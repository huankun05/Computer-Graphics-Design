# 图形画板 — 计算机图形学课程项目

> 一个持续演进的“课程内容可视化平台”：**应用模式**是像素画板软件，
> **演示模式**把每个算法的底层实现逐像素动画拆开给你看。
> 每次课程实验作为一个模块接入（当前：模块一 颜色模型 + 模块二 基本图元生成
> + 模块三 二维几何变换 + 模块四 区域裁剪）。

本仓库仅包含项目源代码、构建配置与测试脚本，不包含实验报告、运行截图和打包产物。

---

## 一、运行方式

环境要求：Python 3.12+、PySide6 6.x。

| 方式 | 操作 |
|---|---|
| 源码运行 | `python main.py` |
| 无控制台启动 | 双击 `启动图形画板.bat` |
| 打包 | `pyinstaller 图形画板.spec --noconfirm`，产物为 `dist/图形画板.exe` |

## 二、两种模式

### 应用模式（像素画板）

画布是 **60×40 的模拟像素网格**（一个网格 = 一个像素，可向四周无限扩展），
所有图元用课程算法逐像素生成——画出来的就是教科书式的像素阶梯。

- **工具**（快捷键 1~9）：DDA/Bresenham 直线、中点圆、中点椭圆、
  多边形描边/扫描线填充、**直线算法对比**（一拖同画两条平行线：
  橙色 DDA / 蓝紫 Bresenham）、橡皮擦、油漆桶、
  **二维变换**（选择/移动/旋转/缩放已合并为一个工具：多选/框选/旋转手柄/
  数值面板，面板实时显示当前角度与比例）、**区域裁剪**
  （裁剪框范式：矩形/任意多边形窗口，可拖手柄调整，Enter 确认后挖除窗口内部分）；
- **右栏**：颜色（点击色块打开 RGB/HSV 联动选色器）、图元列表
  （选中/显隐/删除）、视图（网格/坐标轴开关、适配窗口）；
- **工程文件**：`.gpad`（JSON 存图元参数），可保存/打开教学示例。

### 演示模式（算法可视化）

切到顶栏“演示模式”——纸面清空，进入教学状态：

- **左侧课程模块目录**：每个模块一个可折叠分节，**默认全部收起**（点标题展开）；
  模块一含 RGB 立方体 / HSV 六棱锥 / 转换推导 3 个交互页，模块二含 6 个演示页
  （DDA / Bresenham / 中点圆 / 中点椭圆 / 扫描线填充 / 两算法平行对比），
  模块三含平移/旋转/缩放/复合 4 页，模块四含编码/中点分割/参数/多边形裁剪 4 页；
- **演示对象 = 画布已有图元**：模块三 4 页不再内置示例，也不再有「对象来源」
  下拉——先在演示画布上画好图元，选中哪个就演示哪个（未选中取最后一个），
  旋转/缩放轴心取该图元包围盒中心；播放时隐藏原件由帧接管；画布无图元时
  只提示，不生成任何示例；
- **初始态常显（橙色参照）**：平移/旋转/缩放/复合播放时，初始形态用橙色
  参照层一直显示，当前帧用蓝色区分；到达最终状态时橙色初始态消失，
  画面只留终态（终帧定格为实色）；
- **变换演示为替换式播放 + 逐帧动画**：每一帧只显示当前形态的那一个图形，
  不累积拖影（DDA/中点圆/填充等其它页仍逐步累积）；没有「步数」参数，矩阵
  **全部由参数直接算出**。默认**原位动画**：把参数算出的最终矩阵按
  `t = i/18 … 1` 逐帧施加，画面平滑形变到终态（18 帧，约 0.25 秒/帧），
  图形**原地**旋转/缩放（不搬动）；右侧矩阵行**固定显示最终矩阵**，不展示
  中途矩阵，只有「进度 k/18」表明动画走到哪一帧，`P′` 也常显终值。
  平移页同样是 18 帧原位动画（每帧都是最终的 `T(dx,dy)`）。勾选参数卡的
  「分解演示：搬到原点 → 变换 → 搬回」则改为**逐阶段动画**——旋转/缩放 3 阶段
  （① `T(−c)` 轴心搬到原点 O，画 c→O 虚线 ② `R(θ)/S` 绕原点变换
  ③ `T(c)·(②)` 搬回），复合 5 阶段（T(−c) → S → R → T(c) → T(dx,dy)）；
  每个阶段内部再分 6 帧平滑过渡 + 末尾 2 帧停留（阶段边界看得清），右侧矩阵行给
  **该阶段的精确矩阵**（阶段内不随帧跳动），阶段名 + 进度标明位置。**复合页始终
  按五阶段演示**——把五步合成一个 M 会同时平移+旋转+缩放，看不出过程；参数卡
  不设「分解演示」开关，改为「按阶段暂停」：勾选后每执行完一个阶段自动暂停，
  点播放继续下一阶段。平移页保留 P→P′ 位移箭头；
  旋转/缩放/复合页不画 P→P′ 箭头，原位动画只标轴心，分解阶段另标原点 O，
  P/P′ 数值留在「决策项监视」。变换页默认 4 帧/秒，速度滑杆可调；
- **裁剪演示沿图形边界逐段遍历**：三种线段裁剪页（编码 / 中点分割 / 参数）
  以画布图元为对象——画的是直线就直接用；画的是多边形就按**各条边**一段段
  判定；画的是圆/椭圆就取它的真实栅格轮廓像素、按绕中心极角排成有序点列，
  每 5~6 个相邻像素切一段（段首尾连成直线，轨迹贴着原轮廓）。动画沿边界
  一段段走，每段当场用本页算法判定「在不在窗口里」，落在窗口内的部分当场
  被挖掉（多边形页取选中/最后画的封闭图形，圆/椭圆超过 12 个顶点抽稀成
  12 边形）；画布为空时只提示先画图形，不会再凭空画一条线段盖在你的图上；
- **裁剪动画 = 真实图元口径（蓝=保留 / 橙=待挖除 / 紫线=当前线段）**：像素层
  画的始终是**真实图元**——还没判定挖除的部分用主色，落在窗口内的部分由
  橙色参照层标出（待挖除），紫色虚线是算法当前正在判定的那一段；
  动画末帧 = 画布真实裁剪结果（窗口外保留部分），播完画布那一瞬画面不跳变
  （“演完即所得”）；
- **边框与填充分成两种颜色**：演示层里**轮廓=主色、填充=淡色**（填充像素全部
  走淡色通道，含窗口内尚未挖除的那部分——否则填充会和轮廓画成同一个颜色，
  整块图元糊成一片、边框根本看不出来）；画布上封闭图元的填充用画布的
  `fill_color`（演示模式用**中性灰**，与演示层主色错开——否则油漆桶填出来的
  内部会和演示层画的轮廓撞成同一个蓝，边框再次消失），且**轮廓画在填充
  之上**，填充不会把边框盖掉；
- **同一个图形可以连续裁多次，结果累积**：换一个窗口再裁一次时，上一轮已经
  裁掉的部分保留不动（只有“重播同一轮动画”才把上一轮还原重来）；判定沿
  **存活的连续边界**走，不会跨过上一轮挖空的缺口。
- **裁剪演示可拖窗口**：四页都可先在演示画布拖出红色裁剪窗口（8 个手柄可
  调整，拖窗内可整体移动），右侧 wx0/wy0/wx1/wy1 自动回填；点播放按新窗口
  逐帧演示判定过程：窗口边框、当前使用的窗口边（红框外侧加粗高亮）、交点、
  端点移动箭头都作为“演算注记”单独绘制（不混入算法输出像素）；轮廓用主色、
  填充用淡色，末帧定格为真实裁剪结果（窗口外保留部分）；
  播放不改动画布图元。监视器按算法给关键量：
  Cohen 区域码用 4 位二进制（如 `1001 左/下`）并直接列出 `code0&code1 /
  code0|code1`，端点处也标同一串码；Liang 显示 p/q/u0/u1 与「收窄」过程；
  Hodgman 逐行统计 内→内 / 内→外 / 外→内 / 外→外 四情形；
- **鼠标悬停看区域划分（Cohen 页）**：在演示画布上移动鼠标，窗口四条边
  以虚线延长到画布边缘，把平面分成 9 个区域（窗口内 + 四边 + 四角），
  每个区域标出自己的二进制区域码（`0000` / `0001` / `0101` …）；鼠标所在
  区域淡蓝高亮并加蓝框，离开画布即消失；
- **真正挖除 = Enter**：演示页/应用模式框好窗口后按 Enter（窗口参数框里回车
  同效）、双击或点「挖除窗口内」→ 窗口内部分消失，Ctrl+Z 一次还原；
- **手画即回放**：直接在画布上画任意图元，松手后自动切到对应演示页、
  把首尾参数读回右侧参数卡，并**逐像素动画重放**生成过程；
- **填充对比**：选填充后先画封闭多边形，闭合后点击图形内部即选定对象，
  双色分阶段对比（A 满格 / B 内缩橙芯）；没有对象时不会播放任何示例；
- **右侧教学面板**（均可折叠）：参数（改数值立即重放）、算法公式、
  **决策项监视**（x/y/err/p 逐步刷新 + 本步人话解释）、播放控制
  （播放/暂停/单步前后/重放/跳末尾，默认 30 步/秒、5~240 可调；裁剪/变换页
  按页放慢到 2 步/秒）；
  **矩阵按真矩阵画**：决策项监视里的 3×3 仿射矩阵用 `MatrixView` 绘制
  （方括号画线 + 等宽数字按列右对齐，不再压成一行折行）；变换四页的
  公式卡底部另附符号矩阵 T(dx,dy) / R(θ) / S(sx,sy)，与实时数值形成对照；
- **交互页（模块一）的计算过程在右侧**：颜色模型三页没有像素画板，右侧换成
  「算法公式 / 计算过程 / 概念说明」三卡。「计算过程」把公式逐项代入当前的
  真实数值，并随滑杆/色轮/色相条实时重算：
  RGB 页 ①归一化（含输入）→ ②三视图投影 → ③CMY 互补 → ④HEX；
  HSV 页 ①归一化 → ②C=v·s → ③H/60 落段 → ④X → ⑤排列合成（含 m）；
  转换页 ①归一化 ②Max/Min/Δ ③V ④S ⑤H 代入 → 结果 → HSV→RGB 反向验证；
  版面为「11px 灰色步骤名 + 13px 等宽代入行 + 135% 行距、节间 9px 留白」，
  中间量保持素色，**只有最终结果**用主题色加粗；跨行公式拆成“公式行 / 结果行”
  两行，避免折在数值中间。页面内不再重复写提示或推导（几何概念收进
  「概念说明」卡，且不与参数说明重复）；
- 空格 = 播放/暂停。

## 三、交互操作表

| 操作 | 行为 |
|---|---|
| 左键拖拽 | 绘制当前工具图元（预览橙色，松开提交） |
| Shift + 拖拽 | 直线 45° 吸附 / 椭圆变正圆 |
| Shift + 单击图元 | 加选 / 减选（二维变换工具，多选）；点手柄时优先按缩放/旋转处理 |
| 空白拖拽（变换工具） | 框选矩形内的图元 |
| 拖包围盒内 / 8 方位手柄 | 平移 / 缩放（多选时整组变换，一步撤销；按住 Shift = 等比） |
| 拖包围盒上方环形箭头 | 绕包围盒中心旋转（Shift 吸附 15°），拖拽时包围盒下方实时显示角度 |
| 二维变换面板 | 平移 dx/dy（dy 正 = 向上）；旋转显示当前累计角（−360°~360°，1° 一档）；缩放显示当前比例（100% 起，单值等比）。任一数值框**回车直接应用**；拖拽手柄实时回填，换选归零 |
| 等比缩放 | Shift+手柄 = x/y 两轴同因子，长宽比不变（侧边手柄时另一轴以该边中点对称扩张）；不按 Shift 只拉单轴；面板缩放恒定等比。手柄判定优先于 Shift 加选，可先按住 Shift 再抓手柄 |
| 旋转中心 | 拖拽旋转过程中在包围盒中心显示定点标记，直观看到绕中心转动 |
| 区域裁剪 | 进入工具不预置红框。矩形：空白拖出窗口；多边形：切到「多边形窗口」逐点单击、点回起点或右键/Enter 闭合（Backspace 回退）。窗口就绪后拖 8 个手柄/顶点可调整（矩形也可数值输入）。按 **Enter / 双击画布 / 窗口参数框内回车 / 「挖除窗口内」** 确认，窗口内部分消失（像素掩膜，作用到所有相交图元，Ctrl+Z 一次还原）；Esc 取消并清除窗口 |
| Esc | 取消进行中的图元 |
| 多边形 | 单击布点；Backspace 回退；Enter / 右键闭合填充 |
| 滚轮 | 指针中心缩放（10%~800%）；缩放时像素网格自适应合并 |
| 空格 + 左键 / 中键 | 平移（应用模式） |
| Ctrl+0 / Ctrl+1 | 适配窗口 / 100% |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 1~9 | 切换工具（直线/圆/椭圆/多边形/直线对比/橡皮擦/填充/二维变换/区域裁剪） |
| Delete / Backspace | 删除选中图元（整组一步撤销；多边形布点时 Backspace 为回退顶点） |
| 变换面板内回车 | 直接应用当前数值（不必再点按钮） |
| Tab | 收起/展开两侧面板（输入框内保持焦点切换） |
| Ctrl+S / Ctrl+Shift+S / Ctrl+O | 导出 PNG / 保存工程 / 打开工程 |
| 画布右键 | 上下文菜单（适配/100%/撤销/清空/导出） |

## 四、架构与测试

```
algorithms/   纯算法层（零 Qt 依赖）：每个算法双出口
              xxx() 最终像素 / xxx_steps() 步骤流（演示契约①）
              transform2d.py 提供 3×3 仿射矩阵内核（平移/旋转/缩放/求逆/
              椭圆协方差换算），ellipse_rotated.py 提供旋转椭圆光栅化；
              cohen_sutherland / midpoint_clip / liang_barsky /
              sutherland_hodgman 提供四种裁剪算法（同样双出口：几何 + 步骤流）
modules/      课程模块层：每个实验一个文件夹（契约②：自动发现）
teaching/     演示引擎：播放器 / 决策项监视 / 像素层（与算法解耦）
core/         文档+命令栈(撤销) / 可增长画布 / 注册表 / 工程文件
ui/           主题(theme.py 唯一样式出处) / SVG 图标 / 双模式面板
tools/        算法基线实现（用于新旧结果逐像素比对）
```

| 测试 | 内容 |
|---|---|
| `render_test.py` | 算法像素级回归（新旧 382 组用例全等）+ 测试图生成 |
| `smoke_test.py` | 离屏功能烟测（191 项：绘制/撤销/工程/演示/交互） |
| `perf_test.py` | 预览路径性能（目标 <16ms/帧，实测最坏 4.70ms） |
| `algo_verify.py` | 算法数学性质校验（端点、对称性、连通性等） |
| `transform_test.py` | 二维变换与裁剪校验（3891 项：矩阵/椭圆换算/类型互转/
  旋转椭圆/工程 v2/三种裁剪算法一致性） |
| `clip_test.py` | 裁剪演示口径校验（207 项：橙色参照层/动画末帧 == 真实裁剪结果/
  边框与填充分色/像素层实际渲染取样/同图连续裁两次必须累积/画布填充色与
  演示层主色必须错开，四页 × 直线/多边形/填充多边形/圆/填充圆/椭圆） |
