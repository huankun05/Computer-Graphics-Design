# 图形画板 — 计算机图形学课程项目

> 一个持续演进的“课程内容可视化平台”：**应用模式**是像素画板软件，
> **演示模式**把每个算法的底层实现逐像素动画拆开给你看。
> 每次课程实验作为一个模块接入（当前：模块一 颜色模型 + 模块二 基本图元生成
> + 模块三 二维几何变换 + 模块四 区域裁剪）。

本仓库仅包含项目源代码、构建配置与测试脚本，不包含实验报告、运行截图和打包产物。

---

## 一、运行方式

环境要求：Python 3.12+、PySide6 6.x。

| 方式 | 操作 |
|---|---|
| 源码运行 | `python main.py` |
| 无控制台启动 | 双击 `启动图形画板.bat` |
| 打包 | `pyinstaller 图形画板.spec --noconfirm`，产物为 `dist/图形画板.exe` |

## 二、两种模式

### 应用模式（像素画板）

画布是 **60×40 的模拟像素网格**（一个网格 = 一个像素，可向四周无限扩展），
所有图元用课程算法逐像素生成——画出来的就是教科书式的像素阶梯。

- **工具**（快捷键 1~9）：DDA/Bresenham 直线、中点圆、中点椭圆、
  多边形描边/扫描线填充、**直线算法对比**（一拖同画两条平行线：
  橙色 DDA / 蓝紫 Bresenham）、橡皮擦、油漆桶、
  **二维变换**（选择/移动/旋转/缩放已合并为一个工具：多选/框选/旋转手柄/
  数值面板，面板实时显示当前角度与比例）、**区域裁剪**
  （裁剪框范式：矩形/任意多边形窗口，可拖手柄调整，Enter 确认后挖除窗口内部分）；
- **右栏**：颜色（点击色块打开 RGB/HSV 联动选色器）、图元列表
  （选中/显隐/删除）、视图（网格/坐标轴开关、适配窗口）；
- **工程文件**：`.gpad`（JSON 存图元参数），可保存/打开教学示例。

### 演示模式（算法可视化）

切到顶栏“演示模式”——纸面清空，进入教学状态：

- **左侧课程模块目录**：每个模块一个可折叠分节，**默认全部收起**（点标题展开）；
  模块一含 RGB 立方体 / HSV 六棱锥 / 转换推导 3 个交互页，模块二含 6 个演示页
  （DDA / Bresenham / 中点圆 / 中点椭圆 / 扫描线填充 / 两算法平行对比），
  模块三含平移/旋转/缩放/复合 4 页，模块四含编码/参数/多边形裁剪 3 页；
- **演示对象 = 画布已有图元**：模块三 4 页不再内置示例，也不再有「对象来源」
  下拉——先在演示画布上画好图元，选中哪个就演示哪个（未选中取最后一个），
  旋转/缩放轴心取该图元包围盒中心；播放时隐藏原件由帧接管；画布无图元时
  只提示，不生成任何示例；
- **初始态常显（橙色参照）**：平移/旋转/缩放/复合播放时，初始形态用橙色
  参照层一直显示，当前帧用蓝色区分；到达最终状态时橙色初始态消失，
  画面只留终态（终帧定格为实色）；
- **变换演示为替换式播放**：每帧只显示当前形态的那一个图形，不累积拖影
  （DDA/中点圆/填充等其它页仍逐步累积）；变换页默认 2 步/秒留出观察停留，
  速度滑杆可调；
- **裁剪演示对象 = 画布图元（任意图形）**：模块四三页不再内置示例——编码/参数
  裁剪页演示画布上选中（或最后画的）任意图元：直线直接裁、多边形逐边裁、
  圆/椭圆按 32 段离散成折线逐段裁；多边形页取选中/最后画的封闭图形，圆/椭圆
  离散成 32 边形；画布为空时只提示先画图形，不会再凭空画一条线段盖在你的图上；
- **裁剪演示可拖窗口**：三页都可先在演示画布拖出红色裁剪窗口（8 个手柄可
  调整，拖窗内可整体移动），右侧 wx0/wy0/wx1/wy1 自动回填；点播放按新窗口
  逐帧演示判定过程，窗口外用橙色常显“将被裁掉的部分”，末帧橙色消失；播放
  只做原理演示，不改动画布图元；
- **真正挖除 = Enter**：演示页/应用模式框好窗口后按 Enter（窗口参数框里回车
  同效）、双击或点「挖除窗口内」→ 窗口内部分消失，Ctrl+Z 一次还原；
- **手画即回放**：直接在画布上画任意图元，松手后自动切到对应演示页、
  把首尾参数读回右侧参数卡，并**逐像素动画重放**生成过程；
- **填充对比**：选填充后先画封闭多边形，闭合后点击图形内部即选定对象，
  双色分阶段对比（A 满格 / B 内缩橙芯）；没有对象时不会播放任何示例；
- **右侧教学面板**（均可折叠）：参数（改数值立即重放）、算法公式、
  **决策项监视**（x/y/err/p 逐步刷新 + 本步人话解释）、播放控制
  （播放/暂停/单步前后/重放/跳末尾，5~240 步/秒）；
- 空格 = 播放/暂停。

## 三、交互操作表

| 操作 | 行为 |
|---|---|
| 左键拖拽 | 绘制当前工具图元（预览橙色，松开提交） |
| Shift + 拖拽 | 直线 45° 吸附 / 椭圆变正圆 |
| Shift + 单击图元 | 加选 / 减选（二维变换工具，多选）；点手柄时优先按缩放/旋转处理 |
| 空白拖拽（变换工具） | 框选矩形内的图元 |
| 拖包围盒内 / 8 方位手柄 | 平移 / 缩放（多选时整组变换，一步撤销；按住 Shift = 等比） |
| 拖包围盒上方环形箭头 | 绕包围盒中心旋转（Shift 吸附 15°），拖拽时包围盒下方实时显示角度 |
| 二维变换面板 | 平移 dx/dy（dy 正 = 向上）；旋转显示当前累计角（−360°~360°，1° 一档）；缩放显示当前比例（100% 起，单值等比）。任一数值框**回车直接应用**；拖拽手柄实时回填，换选归零 |
| 等比缩放 | Shift+手柄 = x/y 两轴同因子，长宽比不变（侧边手柄时另一轴以该边中点对称扩张）；不按 Shift 只拉单轴；面板缩放恒定等比。手柄判定优先于 Shift 加选，可先按住 Shift 再抓手柄 |
| 旋转中心 | 拖拽旋转过程中在包围盒中心显示定点标记，直观看到绕中心转动 |
| 区域裁剪 | 进入工具不预置红框。矩形：空白拖出窗口；多边形：切到「多边形窗口」逐点单击、点回起点或右键/Enter 闭合（Backspace 回退）。窗口就绪后拖 8 个手柄/顶点可调整（矩形也可数值输入）。按 **Enter / 双击画布 / 窗口参数框内回车 / 「挖除窗口内」** 确认，窗口内部分消失（像素掩膜，作用到所有相交图元，Ctrl+Z 一次还原）；Esc 取消并清除窗口 |
| Esc | 取消进行中的图元 |
| 多边形 | 单击布点；Backspace 回退；Enter / 右键闭合填充 |
| 滚轮 | 指针中心缩放（10%~800%）；缩放时像素网格自适应合并 |
| 空格 + 左键 / 中键 | 平移（应用模式） |
| Ctrl+0 / Ctrl+1 | 适配窗口 / 100% |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 1~9 | 切换工具（直线/圆/椭圆/多边形/直线对比/橡皮擦/填充/二维变换/区域裁剪） |
| Delete / Backspace | 删除选中图元（整组一步撤销；多边形布点时 Backspace 为回退顶点） |
| 变换面板内回车 | 直接应用当前数值（不必再点按钮） |
| Tab | 收起/展开两侧面板（输入框内保持焦点切换） |
| Ctrl+S / Ctrl+Shift+S / Ctrl+O | 导出 PNG / 保存工程 / 打开工程 |
| 画布右键 | 上下文菜单（适配/100%/撤销/清空/导出） |

## 四、架构与测试

```
algorithms/   纯算法层（零 Qt 依赖）：每个算法双出口
              xxx() 最终像素 / xxx_steps() 步骤流（演示契约①）
              transform2d.py 提供 3×3 仿射矩阵内核（平移/旋转/缩放/求逆/
              椭圆协方差换算），ellipse_rotated.py 提供旋转椭圆光栅化；
              cohen_sutherland / liang_barsky / sutherland_hodgman 提供
              三种裁剪算法（同样双出口：几何 + 步骤流）
modules/      课程模块层：每个实验一个文件夹（契约②：自动发现）
teaching/     演示引擎：播放器 / 决策项监视 / 像素层（与算法解耦）
core/         文档+命令栈(撤销) / 可增长画布 / 注册表 / 工程文件
ui/           主题(theme.py 唯一样式出处) / SVG 图标 / 双模式面板
tools/        算法基线实现（用于新旧结果逐像素比对）
```

| 测试 | 内容 |
|---|---|
| `render_test.py` | 算法像素级回归（新旧 382 组用例全等）+ 测试图生成 |
| `smoke_test.py` | 离屏功能烟测（190 项：绘制/撤销/工程/演示/交互） |
| `perf_test.py` | 预览路径性能（目标 <16ms/帧，实测最坏 4.70ms） |
| `algo_verify.py` | 算法数学性质校验（端点、对称性、连通性等） |
| `transform_test.py` | 二维变换与裁剪校验（3889 项：矩阵/椭圆换算/类型互转/
  旋转椭圆/工程 v2/三种裁剪算法一致性） |
